# dlwlzzero.github.io

Source for my personal site. Jekyll (minima) on GitHub Pages.

- `index.md` — bio / CV, with the paper note list appended below it
- `_posts/` — paper notes, named `YYYY-MM-DD-slug.md`
- `assets/main.scss` — heading scale overrides on top of minima

Edit → commit → push. GitHub Pages rebuilds in ~60s.
